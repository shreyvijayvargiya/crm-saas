## 1. Executive Summary

This is a **Next.js 12 (Pages Router) + React 17** frontend template for a full-featured **CRM SaaS product**. It ships **60+ production UI screens** across sales, operations, finance, marketing, e-commerce, CMS, developer tools, and system administration.

**Key characteristics:**
- **Dual-surface product:** A public **Agency marketing site** at `/` (no CRM shell) and a dense **CRM application** at `/demo` and other routes (sidebar + navbar + AI chat panel).
- **Mock/in-memory data:** No database is connected at runtime. All CRM entities live in React context (`CrmDataContext`) seeded from `app/**/**SeedData.js` files.
- **AI-native:** Built-in CRM assistant via OpenRouter with tool-calling that reads/writes the in-memory CRM snapshot.
- **API-ready:** Zod schemas (`schemas/`), reference SQL (`schemas/sql-schemas/`), and `data.json` document expected API shapes for backend integration.
- **Design system:** Documented in `Design.md`; shadcn/ui + Radix + Tailwind CSS.

**Dev server:** `npm run dev` → http://localhost:3002 (port 3002, not 3000)

### 3.2 Request / Render Flow

```
User navigates to URL
    ↓
pages/*.js (Next.js route)
    ↓
app/*/index.jsx (feature component)
    ↓
useCrmData() / local state / seed data
    ↓
UI render (tables, kanban, charts, modals)
```

For pages with CRM layout:
```
pages/_app.js
    ↓
ThemeProvider → ThemeCustomizerProvider → CrmDataProvider → AIChatProvider
    ↓
LayoutWrapper (unless Component.disableLayout === true)
    ├── Sidebar (nav from navConfig.js)
    ├── Navbar (search, theme, AI toggle)
    ├── ThemeCustomizer
    ├── AIChatSidebar (desktop panel / mobile drawer)
    └── {Page Component}
```

### 3.3 Layout Modes

| Mode | Routes | Shell |
|------|--------|-------|
| **Agency (public)** | `/`, `/pricing`, `/contact`, `/faq` | `AgencyShell` — no sidebar; `disableLayout = true` |
| **CRM (app)** | All other routes | `LayoutWrapper` — sidebar + navbar + AI panel |
| **Unwired** | `app/LandingPage/index.jsx` | Alternate marketing page; not connected to any route |

Agency pages set `Component.disableLayout = true` on their exported component.

## 4. Global State & Contexts

### 4.1 CrmDataContext (`utils/CrmDataContext.jsx`)

Central in-memory store for all CRM entities. Initialized from `lib/ai/crmSnapshot.js` → `buildDefaultCrmSnapshot()`.

**Entities managed (28 keys):**
`leads`, `leadPipelines`, `deals`, `pipelineDeals`, `taskSections`, `activities`, `contacts`, `companies`, `sales`, `invoices`, `projects`, `products`, `payments`, `users`, `teamMembers`, `campaigns`, `segments`, `marketingForms`, `subscriptions`, `subscriptionPlans`, `ecommerceOrders`, `supportTickets`, `files`, `blogs`, `newsletters`, `webhooks`, `integrations`, `apiKeys`, `apiLogs`, `emailThreads`, `calendarEvents`, `notifications`

**Key methods:**
- `useCrmData()` — access all entity state + setters
- `getSnapshot()` — serialize full CRM state (used by AI)
- `applySnapshot(snapshot)` — bulk replace state (used by AI tool-calling)
- `removeLead(leadId)` — cascade delete from leads + pipelines

### 4.2 AIChatContext (`utils/AIChatContext.jsx`)

- Manages chat sessions (stored in `sessionStorage`)
- Sends messages to `POST /api/ai/chat` with current CRM snapshot + page context
- Applies AI-returned snapshot mutations via `CrmDataContext.applySnapshot()`

### 4.3 ThemeContext (`utils/ThemeContext.jsx`)

- Light/dark mode toggle
- Persists to localStorage
- Sets body background color

### 4.4 ThemeCustomizerContext (`utils/ThemeCustomizerContext.jsx`)

- User-selectable accent schemes: blue (default), green, purple, orange, red, pink, indigo, zinc
- Controls primary button colors, chips, focus rings via `useTheme()`

### 4.5 AgencyThemeContext (`app/AgencySite/AgencyThemeContext.jsx`)

- Separate light/dark toggle for agency marketing pages
- Key: `crm-agency-theme`

- **Env:** SMTP_USER, SMTP_PASS_CRM_SAAS_CRM_SAAS (or similar SMTP vars)

## 8. AI Assistant System

### 8.1 Architecture

```
User types in AIChatSidebar
    ↓
AIChatContext.sendMessage()
    ↓
POST /api/ai/chat { messages, crmSnapshot, pageContext }
    ↓
lib/ai/openrouter.js → runCrmAssistantChat()
    ├── buildSystemPrompt(pageContext)
    ├── OpenRouter API call with CRM_TOOL_DEFINITIONS
    ├── Tool execution loop (max 6 rounds)
    │   └── lib/ai/tools.js → executeCrmTool()
    └── Return { reply, updatedSnapshot }
    ↓
AIChatContext applies updatedSnapshot via CrmDataContext
    ↓
UI re-renders with mutated CRM data
```

### 8.2 AI Chat Sidebar Features (`modules/AIChatSidebar/`)
- Multi-chat session management (sessionStorage)
- Prompt templates (`lib/ai/promptTemplates.js`)
- Speech-to-text (Web Speech API)
- File/image attach UI (visual only)
- Markdown responses (`components/ui/chat-markdown.jsx`)
- Deep links to CRM records (`lib/ai/actionLinks.js`)
- Desktop: 384px side panel; Mobile: drawer overlay

### 8.3 CRM AI Tools (`lib/ai/tools.js`)
The assistant can perform CRUD on CRM entities via tool-calling:
- List/search/create/update/delete leads, deals, contacts, companies
- Move leads between pipeline stages
- Create tasks, log activities
- Query sales, invoices, projects

### 8.4 Key AI Files
| File | Purpose |
|------|---------|
| `lib/ai/openrouter.js` | OpenRouter API client + tool loop |
| `lib/ai/tools.js` | Tool definitions + execution |
| `lib/ai/systemPrompt.js` | System prompt builder |
| `lib/ai/promptTemplates.js` | User-facing prompt shortcuts |
| `lib/ai/crmSnapshot.js` | Snapshot builder from seed data |
| `lib/ai/actionLinks.js` | Deep link generation for AI responses |
| `utils/AIChatContext.jsx` | React context for chat state |
| `pages/api/ai/chat.js` | API route handler |

## 10. Design System (Design.md Summary)

### 10.1 Dual Surface
1. **Marketing/Agency** — Violet-indigo gradients, grid texture, editorial hero, more whitespace
2. **CRM App** — Zinc neutrals, dense information, bordered cards, user-selectable accent

### 10.2 Color System
- **Neutrals:** Tailwind zinc scale (not pure black/white)
- **Accent schemes:** blue (default), green, purple, orange, red, pink, indigo, zinc
- **Semantic:** emerald (success), red (destructive), violet (AI FAB)
- **CSS variables:** HSL tokens in `globals.css` for shadcn compatibility

### 10.3 Typography
- Default Tailwind `font-sans` (system UI stack)
- Weights: semibold (titles), medium (buttons), regular (body)
- Icons: Lucide React at 14–20px

### 10.4 Layout Patterns
- App shell: `md:p-2 gap-2`, sidebar `h-[98vh] rounded-xl`, main `rounded-2xl`
- Cards: `border rounded-xl shadow-sm` (light) / `shadow-lg` (dark)
- Tables: @tanstack/react-table with sort/filter/pagination

## 13. Adding New Features

### 13.1 New CRM Page Checklist
1. Create `app/NewModule/index.jsx` with feature UI
2. Export from `app/index.jsx`
3. Create `pages/new-module.js` route file
4. Add to `modules/navConfig.js` (sidebar + search)
5. Create seed data `app/NewModule/newModuleSeedData.js`
6. Add to `lib/ai/crmSnapshot.js` CRM_SNAPSHOT_KEYS
7. Add state to `utils/CrmDataContext.jsx`
8. Create Zod schema in `schemas/zod-schemas/`
9. Add `appNewModule` section to `data.json` (reference)
10. Follow patterns in `Design.md`

### 13.2 Backend Integration Steps
1. Create `lib/api/config.js` and `lib/api/client.js`
2. Create per-module API services (`lib/api/leads.js`, etc.)
3. Replace `useCrmData()` calls with API fetch in `useEffect`
4. Validate responses with Zod `parse()` / `safeParse()`
5. Add loading states and error handling
6. Set `NEXT_PUBLIC_API_BASE_URL` in `.env.local`
