# Componentry

One-page Next.js product that sells a growing kit of UI / motion **hero components**.

## Product

- **Name:** Componentry
- **Surface:** Single route `/` only (`pages/index.js` → `app/AgencySite/pages/HomePage.jsx`)
- **No CRM, no auth, no nested app routes**
- **Buy:** Navbar + footer CTA → `CHECKOUT` in `app/AgencySite/agencyConfig.js` (Gumroad / Dodo)
- **Theme:** Light / dark via `AgencyThemeContext` (key `componentry-theme`)

## Stack

- Next.js 12 Pages Router · React 17 · Tailwind · shadcn/ui · Framer Motion · Lucide · sonner
- Agency shell: `AgencyShell` + `DynamicIslandNav` + `AgencyFooter`
- No `modules/Layout`, no `CrmDataContext`, no AI chat providers

## Catalog (add components here)

All sellable demos are registered in:

`app/AgencySite/componentryCatalog.js` → `COMPONENTRY`

Each entry:

| Field | Purpose |
|-------|---------|
| `id` | URL query `/?c=<id>` + section `id` |
| `name` / `description` / `tags` | Cmd+K search |
| `Component` | Hero React component |
| `needsShots` | Passes `PREVIEW_SHOTS` |
| `bare` | No `isLight` prop |

### Add a new component

1. Create `app/AgencySite/components/HeroYourThing.jsx`
2. Append an entry to `COMPONENTRY` in `componentryCatalog.js`
3. It appears on `/`, in ⌘K search, and as `/?c=your-id`

## Deep links & search

- **Query:** `/?c=iphone` (shallow) scrolls to `#iphone` and briefly highlights it
- **Search:** ⌘K / Ctrl+K → `ComponentSearchModal` → sets `?c=`

## Key paths

```
pages/_app.js              # bare app (no CRM layout)
pages/_document.js         # Componentry meta
pages/index.js             # HomePage

app/AgencySite/
  agencyConfig.js          # PRODUCT, CONTACT, CHECKOUT
  componentryCatalog.js    # COMPONENTRY registry
  AgencyThemeContext.jsx
  pages/HomePage.jsx
  components/
    AgencyShell.jsx
    DynamicIslandNav.jsx   # Search · Theme · Buy
    ComponentSearchModal.jsx
    AgencyFooter.jsx
    Hero*.jsx              # demos
```

## Pack for Gumroad

```bash
npm run pack
```

Creates `tmp/componentry-v<version>-<date>.zip` with all `Hero*.jsx` demos, cursor-trails, minimal UI primitives, and a README. Upload that ZIP to Gumroad.

Options: `node scripts/pack-componentry.mjs --out tmp --name componentry`
